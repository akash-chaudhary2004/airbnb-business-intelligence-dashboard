# Airbnb Business Intelligence Dashboard

## Project Overview

This project is an end-to-end Business Intelligence and Data Analytics solution developed using **Python**, **Tableau Public**, and **CSV/Excel-based data processing**.

The dashboard analyzes **12,805 global Airbnb listings** to uncover valuable business insights related to:

* Pricing trends
* Geographic distribution
* Country-wise performance
* Customer ratings
* Amenities availability
* Market segmentation
* KPI analysis

The project demonstrates practical industry-level skills in:

* Data Cleaning
* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Business Intelligence Reporting
* Interactive Dashboard Development
* Geographic Visualization
* Data Storytelling
* KPI Monitoring

Multiple interactive dashboards were created using Tableau Public with dynamic filters, highlight actions, dashboard actions, and cross-chart interactivity.

# Key Business Insights

* India contains the highest number of Airbnb listings in the dataset.
* Standard category properties dominate the Airbnb market.
* Average ratings across countries remain above 4.7.
* Luxury segment contributes the smallest market share.
* Wifi and AC are highly common amenities across listings.
* Geographic analysis reveals pricing variation across countries.
